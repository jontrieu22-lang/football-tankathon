# UI review checklist

- Run `node scripts/check.cjs`.
- Start the static server and run the browser check documented in README.
- Review at desktop (1440px) and mobile (390px) widths.
- Verify navigation, visible focus, button disabled states, text contrast, and reduced-motion behavior.
- Confirm tables scroll within their containers without page-wide overflow.
- Exercise offseason signing/trading, the full draft board, pick trades, kickoff, and game results.
- Reload during a run and mid-draft to verify saves remain compatible.
- Check the chair at secure, warm, hot, and critical heat levels.
- Include before/after screenshots and the affected flows in the PR description.
- Review the Vercel branch preview before merging to main.
